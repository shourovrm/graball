graball · Google Drive folder — what breaks, what it should look like

Reproduced on the physical device against drive.google.com/drive/folders/…. Two independent defects; one shared root cause in the extension parser.

1 — share-sheet path: yt-dlp's GoogleDrive:Folder extractor dies (expected string or bytes-like object, got 'bool'), so the user falls back to the in-app browser. 2 — browser sniffer path: it grabs Drive's thumbnail CDN URLs (lh3.googleusercontent.com/u/0/d/…), which have no filename and no extension, so the name becomes the opaque CDN id and the "extension" becomes whatever follows the last dot in the whole URL — the host tail. 3 — the fix.
